Topological Data Analysis / Demos

Topological data analysis

Topological data analysis (TDA) uses tools from algebraic topology to study different kinds of data, including point clouds and branching trees. I’ve coded up a few small demos to show some use cases.

Point clouds: the Vietoris–Rips complex

Increase the connection distance to join nearby points. Three mutually connected points fill a triangle. The counters track connected components and unfilled loops.

What am I looking at?

This is the 2-skeleton of a Vietoris–Rips complex. An edge joins points at distance at most ε; a triangle is filled when all three edges are present. The displayed counts are computed from the complex at the current scale.

β₀ counts connected components. β₁ counts independent unfilled loops, using homology over ℤ₂. Higher-dimensional simplices do not change these two counts. This is an illustration of the filtration used in persistent homology; it does not compute a persistence barcode.

The point clouds are synthetic examples. Distances are in arbitrary units.

TMD: from a tree to a barcode

Lida Kanari and colleagues’ Topological Morphology Descriptor (TMD) summarises a branching tree as a persistence barcode. Move the circle towards the soma: separate tips meet at branch points and merge. The branch with the furthest-reaching tip continues.

SomaFurthest tip

How is the barcode computed?

Starting at the tips, walk towards the soma. At each junction, keep the component whose tip is furthest from the soma. Record each other component as an interval from the junction’s radius to its tip’s radius. Finally, record the surviving component from zero to the furthest tip. A coloured branch can pass through several junctions.

This example uses synthetic trees whose radius increases along every branch. The highlighted pieces are the part of the tree outside the circle. Units are arbitrary; these are not measured neurons.

Kanari, Dłotko, Scolamiero et al. (2018). A Topological Representation of Branching Neuronal Morphologies. Neuroinformatics 16, 3–13. TMD software ↗

TNS: from a barcode to a tree

A synthetic tree is analysed with TMD, then its barcode is used by NeuroTS to generate new trees. The three recordings below were computed locally with the authors’ software. Play or scrub through the growth, or switch recordings to see a different result from the same input.

SomaComplete tree

Generated with NeuroTS 3.7.0; the barcode was extracted with TMD 2.4.3. This example grows one apical dendrite in 3D and displays a 2D projection. Playback follows the recorded algorithm steps, not biological time. Download this tree (SWC).

What is being reproduced?

TMD uses path distance along the source tree here; the earlier toy example uses radial distance. NeuroTS receives the source barcode and associated branch-angle information, together with the authors’ example growth settings. It samples growth, bifurcations, and terminations. The result need not have exactly the same barcode or branching structure, so TNS is a stochastic approximate inverse rather than a unique reconstruction.

The source tree was also generated with NeuroTS, using the authors’ example inputs. It is not a biological reconstruction. All three output recordings use its extracted barcode; only the random seed changes.

Kanari, Garin & Hess (2020). From Trees to Barcodes and Back Again: Theoretical and Statistical Perspectives. Algorithms 13, 335.

Kanari, Dictus, Chalimourda et al. (2022). Computational synthesis of cortical dendritic morphologies. Cell Reports 39, 110586. NeuroTS software ↗
